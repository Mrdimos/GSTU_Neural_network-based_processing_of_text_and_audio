## 1. Цель работы

Сравнить два способа определения тональности: TF-IDF с логистической регрессией и готовую нейросетевую модель. Изучить, на каких примерах они ошибаются, как связана уверенность модели с её правильностью и как модель может отказываться от ответа, если уверенность низкая.

## 2. Что нужно знать

**Тональность и эмоция.** Тональность (sentiment) — полярность текста: положительная или отрицательная. Эмоция — конкретное состояние: радость, страх, гнев и т. д. Это разные задачи с разными метками, их нельзя смешивать без явного соответствия между метками.

**Трудности.** Отрицание («не понравилось»), усилители («совсем плохо»), сарказм («Прекрасно, опять сломалось») и смешанные оценки в одном предложении. Простые модели на словах их часто не учитывают, а контекстные модели ошибаются реже, но не всегда.

**Многоклассовая и многометочная классификация.** В многоклассовой постановке у текста один класс, в многометочной — несколько одновременно (например, радость и удивление), и для каждой метки используется свой порог.

**Уверенность модели.** Вероятность на выходе — не гарантия правильности. Модель может ошибаться с высокой уверенностью. Для оценки смотрят долю ошибок среди примеров с разной уверенностью и строят правило отказа от ответа: если уверенность ниже порога, система передаёт пример человеку.

### Шаг 1. Baseline: TF-IDF + логистическая регрессия

```python
from sklearn.pipeline import Pipeline
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import classification_report, f1_score, accuracy_score, ConfusionMatrixDisplay

baseline = Pipeline([
    ("tfidf", TfidfVectorizer(ngram_range=(1, 2), min_df=2, sublinear_tf=True)),
    ("clf", LogisticRegression(max_iter=2000)),
])
baseline.fit(train["text"], train["label"])
pred_base = baseline.predict(test["text"])
proba_base = baseline.predict_proba(test["text"])[:, 1]

print(classification_report(test["label"], pred_base, target_names=["neg", "pos"], digits=3))
ConfusionMatrixDisplay.from_predictions(test["label"], pred_base, display_labels=["neg", "pos"])
plt.show()
```

### Шаг 2. Готовая нейросетевая модель

Модель `distilbert-base-uncased-finetuned-sst-2-english` уже дообучена на обучающей части SST-2, поэтому проверять её на validation корректно. Но результат нельзя называть «качеством модели на любых отзывах», это качество на домене SST-2.

```python
from transformers import pipeline

clf_nn = pipeline("text-classification",
                  model="distilbert-base-uncased-finetuned-sst-2-english",
                  truncation=True, batch_size=32)   # device=0 для GPU

t0 = time.time()
out = clf_nn(test["text"].tolist())
t_nn = time.time() - t0

pred_nn = np.array([1 if o["label"] == "POSITIVE" else 0 for o in out])
conf_nn = np.array([o["score"] for o in out])     # уверенность в выбранном классе
print(classification_report(test["label"], pred_nn, target_names=["neg", "pos"], digits=3))
print(f"время: {t_nn:.1f} с")
```

### Шаг 5. Уверенность и отказ от ответа

```python
# доля ошибок нейросети в зависимости от уверенности
bins = [0.5, 0.7, 0.9, 0.99, 1.0]
res["conf_bin"] = pd.cut(res["conf_nn"], bins=bins, include_lowest=True)
print(res.groupby("conf_bin", observed=True)["wrong_nn"].agg(["mean", "size"]).round(3))

# правило отказа: отвечаем только если уверенность >= порога
for thr in [0.6, 0.8, 0.9, 0.95, 0.99]:
    keep = res["conf_nn"] >= thr
    print(f"порог {thr}: отвечает {keep.mean():.1%}, ошибок среди ответов {res.loc[keep, 'wrong_nn'].mean():.1%}")
```
