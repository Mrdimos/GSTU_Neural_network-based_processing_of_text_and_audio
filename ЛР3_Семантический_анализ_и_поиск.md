# Лабораторная работа № 3. Семантический поиск: TF-IDF и эмбеддинги

## 1. Цель работы

Сравнить лексический поиск (TF-IDF) и семантический поиск по эмбеддингам на небольшом русскоязычном корпусе. Научиться считать метрики поиска Recall@k и MRR и анализировать случаи, когда поиск ошибается.

## 2. Что нужно знать

**Эмбеддинг** — числовой вектор фиксированной длины, который кодирует смысл текста. Близкие по смыслу тексты должны иметь близкие векторы, даже если слова в них разные.

**Косинусное сходство** двух векторов `u` и `v`:

cos(u, v) = (u · v) / (‖u‖ · ‖v‖).

Если векторы нормализованы (длина 1), оно равно скалярному произведению. Значение косинуса — не вероятность релевантности, поэтому одним и тем же порогом для разных моделей пользоваться нельзя.

**Лексический поиск** (TF-IDF, BM25) хорошо находит точные слова, имена и номера версий, но не понимает синонимов. **Семантический поиск** лучше находит перефразирования, но может упустить редкий точный термин.

**Метрики.** Для каждого запроса известно множество релевантных документов:

- **Recall@k** — доля релевантных документов, найденных среди первых `k` результатов;
- **MRR** — среднее значение `1 / r`, где `r` — позиция первого релевантного документа в выдаче;
- **Precision@k** — доля релевантных среди первых `k`.

## 3. Данные

В папке `data/` лежат два файла, их выдаёт преподаватель:

- `lr3_corpus.csv` — 30 коротких документов (`doc_id`, `text`) по теме «машинное обучение и работа в Colab»;
- `lr3_queries.csv` — 20 запросов (`query_id`, `query`, `relevant`), в колонке `relevant` указаны идентификаторы релевантных документов через точку с запятой.

Запросы специально сформулированы по-другому, чем документы (кроме двух, где важны точные термины), поэтому сравнение методов наглядно. Корпус маленький, так что результаты нельзя считать доказательством качества методов в целом, это учебная демонстрация.

### Шаг 1. Функции метрик

```python
def rank_docs(score_matrix):
    """score_matrix: (n_queries, n_docs). Возвращает для каждого запроса id документов по убыванию."""
    order = np.argsort(-score_matrix, axis=1)
    return [[doc_ids[j] for j in row] for row in order]

def recall_at_k(ranked, relevant_sets, k):
    vals = [len(set(r[:k]) & rel) / len(rel) for r, rel in zip(ranked, relevant_sets)]
    return float(np.mean(vals))

def mrr(ranked, relevant_sets):
    vals = []
    for r, rel in zip(ranked, relevant_sets):
        pos = next((i + 1 for i, d in enumerate(r) if d in rel), None)
        vals.append(1 / pos if pos else 0.0)
    return float(np.mean(vals))

def evaluate(score_matrix, name):
    ranked = rank_docs(score_matrix)
    rel = queries["relevant"].tolist()
    return {"метод": name,
            "Recall@1": recall_at_k(ranked, rel, 1),
            "Recall@3": recall_at_k(ranked, rel, 3),
            "Recall@5": recall_at_k(ranked, rel, 5),
            "MRR": mrr(ranked, rel)}
```

### Шаг 2. Лексический поиск (TF-IDF)

Для русского языка в TF-IDF полезно использовать символьные n-граммы: они частично заменяют стемминг.

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

vec = TfidfVectorizer(analyzer="char_wb", ngram_range=(3, 5), sublinear_tf=True)
D = vec.fit_transform(doc_texts)
Q = vec.transform(queries["query"])
scores_tfidf = cosine_similarity(Q, D)
res_tfidf = evaluate(scores_tfidf, "TF-IDF (символьные n-граммы)")
res_tfidf
```

### Шаг 3. Семантический поиск

```python
from sentence_transformers import SentenceTransformer

enc = SentenceTransformer("sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2")
D_emb = enc.encode(doc_texts, normalize_embeddings=True)
Q_emb = enc.encode(queries["query"].tolist(), normalize_embeddings=True)
scores_emb = Q_emb @ D_emb.T          # косинус для нормализованных векторов
res_emb = evaluate(scores_emb, "Эмбеддинги MiniLM (мультиязычные)")

pd.DataFrame([res_tfidf, res_emb]).round(3)
```
