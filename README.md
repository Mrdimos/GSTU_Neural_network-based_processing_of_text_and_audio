# Методические указания по дисциплине «Нейросетевая обработка текста и звука»

Комплект рассчитан на **студентов 4 курса бакалавриата**. Практикум построен на работе с готовыми моделями и стандартными библиотеками: студент запускает проверенный код, сравнивает методы, считает метрики и разбирает ошибки. Обучать сложные сети с нуля не требуется.

## Состав комплекта

| № | Файл | Тема | Данные (фиксированные) | GPU |
|---|---|---|---|---|
| 1 | [`ЛР1_Классификация_текста.md`](ЛР1_Классификация_текста.md) | TF-IDF и эмбеддинги Transformer | AG News, подвыборка 8 000 / 2 000 | желательно |
| 2 | [`ЛР2_Тональность_и_эмоции.md`](ЛР2_Тональность_и_эмоции.md) | тональность, уверенность модели | SST-2 (GLUE), 8 000 / 872 | желательно |
| 3 | [`ЛР3_Семантический_анализ_и_поиск.md`](ЛР3_Семантический_анализ_и_поиск.md) | семантический поиск | учебный мини-корпус из `data/` (30 документов, 20 запросов) | не нужен |
| 4 | [`ЛР4_Классификация_звуков.md`](ЛР4_Классификация_звуков.md) | спектрограммы, MFCC, SVM | ESC-10 (подмножество ESC-50, 400 клипов) | не нужен |
| 5 | [`ЛР5_Распознавание_речи.md`](ЛР5_Распознавание_речи.md) | ASR, WER/CER, шум | 10 фраз, которые студент записывает сам | нужен |

В папке `data/` лежат `lr3_corpus.csv` и `lr3_queries.csv`. Их нужно выдать студентам вместе с методичкой ЛР3.

## Как устроена каждая работа

Одна работа рассчитана на 4 академических часа (две пары) плюс оформление отчёта дома. Это ориентир: время работы кода я оценил по тексту и не замерял, поэтому прогоните ноутбуки сами.

1. **Часть А — общая обязательная.** Все студенты работают с одним и тем же набором и готовым кодом, выполняют по порядку 5–7 шагов и отвечают на вопросы в ноутбуке.
2. **Часть Б — индивидуальный эксперимент.** Один вариант из 22. Вариант — небольшое изменение или сравнение поверх части А, его можно сделать, поменяв несколько строк кода. Сложность отмечена: ★ — простой, ★★ — средний, ★★★ — повышенной сложности (на дополнительные баллы, назначается по желанию).
3. **Отчёт — ноутбук `.ipynb`** с результатами и текстовыми выводами. Отдельный документ не требуется.

Варианты 1–15 назначайте как основные (★ и ★★). Варианты ★★★ выдавайте только тем, кто выразил желание.

## Оценивание (10 баллов за работу)

| Критерий | Баллы |
|---|---:|
| Часть А выполнена, код запускается от начала до конца | 4 |
| Часть Б: эксперимент проведён, результат сведён в таблицу или график | 3 |
| Разбор ошибок: не менее 3 примеров с объяснением причин | 2 |
| Выводы, оформление, указаны источник данных и параметры (`random_state`, модель) | 1 |

Вариант ★★★ при полном выполнении даёт до +2 баллов к оценке за работу.

## Среда: Google Colab

- Бесплатной сессии Colab достаточно для всех работ. GPU включается через «Среда выполнения → Сменить тип среды выполнения → T4 GPU». Для ЛР5 GPU практически обязателен, для ЛР1 и ЛР2 ускоряет работу в разы, для ЛР3 и ЛР4 не нужен.
- Сессия может отключиться после простоя, а файлы во временном хранилище при этом пропадают. Результаты и записи сохраняйте на Google Диск или скачивайте на компьютер.
- Основные библиотеки (`numpy`, `pandas`, `scikit-learn`, `matplotlib`, `torch`, `transformers`) в Colab уже установлены, переустанавливать их не нужно. В каждой работе в первой ячейке указано, что нужно доустановить.
- Первый запуск скачивает данные и модели из интернета, поэтому он занимает больше времени. В аудитории проверьте, что сеть доступна и студентов не блокирует.
- Версии библиотек в Colab обновляются. Если ячейка внезапно перестала работать, зафиксируйте версию (`pip install "библиотека==версия"`) и сохраните версию в ноутбуке-заготовке.

## Данные и лицензии

- **AG News** (ЛР1) и **SST-2 / GLUE** (ЛР2) загружаются через библиотеку `datasets`. Используйте их только для учебных целей и не публикуйте копии. Лицензию проверяйте на карточке набора.
- **dair-ai/emotion** (дополнительные варианты ЛР2): в карточке лицензия указана как `other/unknown`. Только для учебных экспериментов, без повторной публикации.
- **ESC-50 / ESC-10** (ЛР4): лицензия CC BY-NC, то есть только некоммерческое использование, с указанием автора набора.
- **Собственные записи** (ЛР5): студент записывает только свой голос и сам решает, передавать ли записи преподавателю. Не публикуйте чужие записи без согласия говорящего.
- Не помещайте в учебные корпуса персональные данные (имена, телефоны, номера зачёток).
