## 2. Что нужно знать

**Классификация текста** — по тексту `x` определить его класс `y` (тема новости, спам или не спам и т. п.).

**TF-IDF.** Текст представляется вектором: каждому слову соответствует вес, который тем больше, чем чаще слово встречается в документе и чем реже во всей коллекции:

tfidf(t, d) = tf(t, d) · log(N / (1 + df(t))),

где `df(t)` — число документов со словом `t`. На таких признаках быстро обучаются логистическая регрессия и линейный SVM. Минус: порядок слов и синонимы не учитываются.

**Эмбеддинг Transformer.** Предобученная модель (например, MiniLM) превращает текст в вектор из нескольких сотен чисел, в котором учтён контекст. Поверх такого вектора можно обучить обычную логистическую регрессию. Дообучать всю модель при этом не нужно.

**Метрики.** Accuracy — доля верных ответов. Precision, Recall, F1 считаются для каждого класса отдельно. Macro-F1 — среднее F1 по классам, все классы учитываются с одинаковым весом.

**Правило эксперимента.** Тест используется только для итоговой оценки. Подбирать параметры по тесту нельзя.

### Шаг 2. Baseline: TF-IDF + линейный SVM

```python
from sklearn.pipeline import Pipeline
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.svm import LinearSVC
from sklearn.metrics import classification_report, f1_score, accuracy_score, ConfusionMatrixDisplay

tfidf_model = Pipeline([
    ("tfidf", TfidfVectorizer(ngram_range=(1, 2), min_df=2, sublinear_tf=True)),
    ("clf", LinearSVC()),
])

t0 = time.time()
tfidf_model.fit(train["text"], train["label"])
t_fit = time.time() - t0

t0 = time.time()
pred_tfidf = tfidf_model.predict(test["text"])
t_pred = time.time() - t0

print(classification_report(test["label"], pred_tfidf, target_names=class_names, digits=3))
print(f"обучение: {t_fit:.1f} с, предсказание: {t_pred:.2f} с")
ConfusionMatrixDisplay.from_predictions(
    test["label"], pred_tfidf, display_labels=class_names, xticks_rotation=30)
plt.tight_layout(); plt.show()
```

### Шаг 3. Эмбеддинги Transformer + логистическая регрессия

Включите GPU в Colab (иначе кодирование 10 000 текстов займёт несколько минут; на CPU можно уменьшить train до 4 000 строк).

```python
from sentence_transformers import SentenceTransformer
from sklearn.linear_model import LogisticRegression

encoder = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")

t0 = time.time()
E_train = encoder.encode(train["text"].tolist(), batch_size=64,
                         normalize_embeddings=True, show_progress_bar=True)
E_test = encoder.encode(test["text"].tolist(), batch_size=64,
                        normalize_embeddings=True, show_progress_bar=True)
t_enc = time.time() - t0

clf_emb = LogisticRegression(max_iter=2000)
clf_emb.fit(E_train, train["label"])
pred_emb = clf_emb.predict(E_test)

print(classification_report(test["label"], pred_emb, target_names=class_names, digits=3))
print(f"кодирование: {t_enc:.1f} с")
```

```python
import random

def add_typos(text, rate=0.1, seed=SEED):
    rnd = random.Random(seed)
    chars = list(text)
    for i in range(len(chars) - 1):
        if chars[i].isalpha() and rnd.random() < rate:
            chars[i], chars[i + 1] = chars[i + 1], chars[i]   # меняем соседние буквы
    return "".join(chars)

test_typo = test.copy()
test_typo["text"] = test_typo["text"].map(lambda s: add_typos(s, rate=0.1))
```
