## 2. Что нужно знать

**Цифровой звук.** Сигнал — последовательность отсчётов амплитуды. **Частота дискретизации** (sample rate) — число отсчётов в секунду. Чтобы сохранить частоты до $f_{\max}$, нужна частота дискретизации $f_s > 2 f_{\max}$ (теорема Найквиста). Для речи обычно хватает 16 кГц, для музыки используют 44,1 кГц.

**Спектрограмма.** Звук нестационарен, поэтому его делят на короткие перекрывающиеся окна и считают спектр каждого (кратковременное преобразование Фурье, STFT). Результат показывает, как энергия по частотам меняется со временем.

**Mel-спектрограмма и MFCC.** Mel-шкала приближённо учитывает то, как человек воспринимает высоту звука. Mel-спектрограмма — спектрограмма, усреднённая по Mel-фильтрам. MFCC получают из логарифма энергий Mel-фильтров с помощью дискретного косинусного преобразования, это компактное описание формы спектра.

**Признаки фиксированной длины.** Клипы одинаковой длины дают матрицы одинакового размера, но классический SVM принимает вектор. Поэтому по времени считают статистики, например среднее и стандартное отклонение каждого коэффициента.

**Корректная оценка.** Клипы из одной исходной записи нельзя разделять между train и test. В ESC-50 это уже учтено: в метаданных у каждого клипа есть номер `fold` (1–5). Для итоговой оценки используют все 5 фолдов по очереди и усредняют результат.

### Шаг 2. Извлечение признаков

```python
def load_clip(path, sr=SR, duration=DUR):
    y, _ = librosa.load(path, sr=sr, mono=True, duration=duration)
    n = int(sr * duration)
    return np.pad(y, (0, max(0, n - len(y))))[:n]

def feat_mfcc(y, sr=SR, n_mfcc=20):
    m = librosa.feature.mfcc(y=y, sr=sr, n_mfcc=n_mfcc)
    return np.concatenate([m.mean(axis=1), m.std(axis=1)])

def feat_logmel(y, sr=SR, n_mels=40):
    S = librosa.feature.melspectrogram(y=y, sr=sr, n_mels=n_mels)
    L = librosa.power_to_db(S, ref=np.max)
    return np.concatenate([L.mean(axis=1), L.std(axis=1)])

import time
t0 = time.time()
clips = [load_clip(p) for p in meta["path"]]
X_mfcc = np.vstack([feat_mfcc(y) for y in clips])
X_mel = np.vstack([feat_logmel(y) for y in clips])
print(X_mfcc.shape, X_mel.shape, f"{time.time() - t0:.0f} с")
```

### Шаг 3. SVM с 5-кратной проверкой по официальным фолдам

```python
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC
from sklearn.metrics import accuracy_score, f1_score, classification_report, ConfusionMatrixDisplay

y_all = meta["category"].to_numpy()

def cv_by_fold(X, make_model):
    preds = np.empty(len(y_all), dtype=object)
    scores = []
    for f in sorted(meta["fold"].unique()):
        tr, te = (meta["fold"] != f).to_numpy(), (meta["fold"] == f).to_numpy()
        model = make_model()
        model.fit(X[tr], y_all[tr])
        preds[te] = model.predict(X[te])
        scores.append(accuracy_score(y_all[te], preds[te]))
    return preds, np.array(scores)

make_svm = lambda: make_pipeline(StandardScaler(), SVC())
pred_mfcc, acc_mfcc = cv_by_fold(X_mfcc, make_svm)
pred_mel, acc_mel = cv_by_fold(X_mel, make_svm)

print("MFCC:    accuracy по фолдам", acc_mfcc.round(3), "среднее", acc_mfcc.mean().round(3))
print("log-Mel: accuracy по фолдам", acc_mel.round(3), "среднее", acc_mel.mean().round(3))
```
