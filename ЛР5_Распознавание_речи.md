## 1. Цель работы

Запустить готовую модель распознавания речи на готовых записях, оценить качество метриками WER и CER и выяснить, как на результат влияют шум и параметры распознавания.

## 2. Что нужно знать

**ASR** (Automatic Speech Recognition) преобразует звук в текст. В работе используется готовая модель Whisper, реализованная в библиотеке `faster-whisper`; обучать её не нужно.

**WER** (Word Error Rate) основан на расстоянии Левенштейна между эталонным и распознанным текстом на уровне слов:

WER = (S + D + I) / N,

где `S` — замены, `D` — пропуски (удаления), `I` — вставки, `N` — число слов в эталоне. WER может быть больше 1. **CER** считается так же, но по символам и менее чувствителен к небольшим ошибкам в словах.

**Нормализация.** До подсчёта метрик эталон и распознанный текст приводят к одному виду (регистр, знаки препинания, «ё/е», числа). Иначе WER покажет ошибки, которых на слух нет. Правила нормализации должны быть одинаковы для эталона и гипотезы, и их нужно указать в отчёте.

**Шум.** Шум, эхо и плохой микрофон ухудшают распознавание. Уровень шума описывают отношением сигнал/шум (SNR, дБ): чем оно меньше, тем шумнее запись.

**Честные выводы.** В работе оценивается модель на небольшой фиксированной выборке из тестовой части FLEURS. Это учебный эксперимент, а не исчерпывающая оценка качества распознавания русского языка: выводы должны учитывать размер и особенности выборки.

```python
import re, time
import numpy as np
import pandas as pd
import librosa
from datasets import load_dataset
from jiwer import wer, cer

# Официальная тестовая выборка русского языка.
# Берём первые 10 элементов для компактного и воспроизводимого эксперимента.
N_SAMPLES = 10
fleurs = load_dataset(
    "google/fleurs",
    "ru_ru",
    split=f"test[:{N_SAMPLES}]"
)

reference = {}
audio = {}
for i, row in enumerate(fleurs, start=1):
    key = f"{i:02d}"
    reference[key] = row["raw_transcription"]

    audio_item = row["audio"]
    y = np.asarray(audio_item["array"], dtype=np.float32)
    sr = int(audio_item["sampling_rate"])
    if sr != 16000:
        y = librosa.resample(y, orig_sr=sr, target_sr=16000)
    audio[key] = y.astype(np.float32)

print("Количество записей:", len(audio))
print("Частота дискретизации: 16000 Гц")
print("Пример эталонного текста:", reference["01"])
print("Длительность первой записи, с:", round(len(audio["01"]) / 16000, 2))
```

### Шаг 1. Подготовка эталонных текстов и нормализация

```python
def normalize(text):
    text = text.lower().replace("ё", "е")
    text = re.sub(r"[^\w\s]", " ", text)
    return " ".join(text.split())

def safe_metric(metric, ref, hyp):
    """Если распознан пустой текст, считаем, что все слова эталона пропущены."""
    return 1.0 if not hyp.strip() else metric(ref, hyp)

# Быстрая проверка соответствия аудио и эталонных строк.
for k in list(reference)[:3]:
    print(k, "|", round(len(audio[k]) / 16000, 2), "с |", reference[k])
```

Эталон берётся из поля `raw_transcription` датасета, а не вводится вручную. Функция `normalize` одинаково применяется к эталону и гипотезе распознавания.

### Шаг 2. Распознавание Whisper

```python
from faster_whisper import WhisperModel

# Для Colab с GPU:
model = WhisperModel("small", device="cuda", compute_type="float16")
# Если GPU недоступен, закомментируйте строку выше и используйте CPU:
# model = WhisperModel("base", device="cpu", compute_type="int8")

def transcribe(y, **kwargs):
    """Распознаёт аудиомассив float32 с частотой 16 кГц."""
    options = {"language": "ru", "beam_size": 5}
    options.update(kwargs)  # позволяет вариантам менять language и beam_size
    segments, info = model.transcribe(y, **options)
    return " ".join(segment.text.strip() for segment in segments)
```

### Шаг 3. WER и CER по файлам

```python
def run_condition(audio_dict, name, **kwargs):
    rows = []
    t0 = time.time()
    for k, y in audio_dict.items():
        hyp = transcribe(y, **kwargs)
        r, h = normalize(reference[k]), normalize(hyp)
        rows.append({"условие": name, "файл": k, "эталон": reference[k], "гипотеза": hyp,
                     "WER": safe_metric(wer, r, h), "CER": safe_metric(cer, r, h)})
    df = pd.DataFrame(rows)
    elapsed = time.time() - t0
    duration = sum(len(y) for y in audio_dict.values()) / 16000
    print(f"{name}: WER={df.WER.mean():.3f}, CER={df.CER.mean():.3f}, "
          f"время {elapsed:.1f} с, RTF={elapsed / duration:.2f}")
    return df

df_clean = run_condition(audio, "чистая запись")
df_clean[["файл", "эталон", "гипотеза", "WER", "CER"]]
```

### Шаг 4. Добавление шума

```python
def add_white_noise(y, snr_db, seed=0):
    p_signal = np.mean(y ** 2)
    p_noise = p_signal / (10 ** (snr_db / 10))
    noise = np.random.default_rng(seed).normal(0, np.sqrt(p_noise), len(y))
    return (y + noise).astype(np.float32)

results = [df_clean]
for snr in [20, 10, 0]:
    noisy = {k: add_white_noise(y, snr) for k, y in audio.items()}
    results.append(run_condition(noisy, f"SNR {snr} дБ"))

all_df = pd.concat(results)
summary = all_df.groupby("условие", sort=False)[["WER", "CER"]].mean().round(3)
summary
```
